# **App Name**: FinAI Edge

## Core Features:

- AI-Powered Insights Tool: Receive intelligent, LLM powered summaries of market trends to better inform your financial decisions. The LLM is a tool that reviews different pieces of market news before deciding if the fact or perspective should be incorporated in its overall response. These insights can be displayed according to preference and further clarified as needed.
- Stock Screener: Filter stocks based on AI-driven technical analysis and user-defined criteria.
- Financial Indicator Display: Visualize financial indicators with interactive charts and graphs.
- Portfolio Tools: Access tools for calculating SIP and optimizing asset allocation. This calculation occurs in the browser - there is no database storage.
- Trading Insights: Gain insights into swing, positional, and F&O trading opportunities.
- Account Creation and Management: Create and manage user accounts for personalized experience.
- Information Pages: Display the FAQ, Privacy Policy, Contact, and similar pages to provide all necessary information for the application.

## Style Guidelines:

- Primary color: Deep sky blue (#30A2FF) for innovation and trust.
- Background color: Light gray (#F0F4F8) for a clean, modern feel.
- Accent color: Turquoise (#40E0D0) for highlighting key elements and calls to action. It is analogous to the primary color, evoking freshness and vitality.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern and neutral appearance, ideal for both headlines and body text.
- Use modern, minimalist icons related to finance, AI, and trading.
- Implement a clean and intuitive layout with rounded cards, smooth animations, and minimal clutter. Mobile-first responsiveness should be prioritized.
- Incorporate subtle animations such as fade-in effects and hover interactions to enhance user engagement.
